# Publishing and Bomberman updates

The live profile is [Abhi-eversor/Abhi-eversor](https://github.com/Abhi-eversor/Abhi-eversor). Its root README uses native Markdown, two static contact buttons and the original upstream Bomberman animation.

## Where the files live

- `main`: README.md, this guide, .gitignore, .github/workflows/bomberman.yml and the two contact-button SVGs in assets/.
- `output`: bomberman-contribution-graph.svg and bomberman-contribution-graph-dark.svg, generated by GitHub Actions.
- `profile-review/`: private local evidence and earlier prototypes, outside the public repository and ZIP.

The README references the SVGs on output using raw.githubusercontent.com URLs. No local Bomberman snapshot or generator script is needed on main. Yashraj's snake workflow uses the same separation between workflow source and generated output.

## Automatic generation

[Refresh Bomberman](.github/workflows/bomberman.yml) uses [abozanona/pacman-contribution-graph](https://github.com/abozanona/pacman-contribution-graph), pinned to `7332e1de7903ab780c3692a4127a59cc13872daa`, with `games: bomberman`. Its built-in GitHub token fetches the profile owner's contribution calendar through GitHub's GraphQL API.

The workflow runs:
- When bomberman.yml is first uploaded or changed on main.
- Daily at **03:17 Asia/Kolkata**.
- When requested through **Actions > Refresh Bomberman > Run workflow**.

Both original GitHub theme SVGs must validate before publication. [crazy-max/ghaction-github-pages](https://github.com/crazy-max/ghaction-github-pages), pinned to `df5cc2bfa78282ded844b354faee141f06b41865`, publishes only dist/ to output and preserves output history. A generation failure leaves the previous output intact. Output commits do not retrigger the main-branch workflow.

The first actual hosted run [completed successfully on 15 October 2026](https://github.com/Abhi-eversor/Abhi-eversor/actions/runs/38699281081). The earlier graph was stale because no workflow had run; it was a bundled 12 October snapshot with 35 contributions.

GitHub displays animated SVG images, not executable README JavaScript. Upstream Bomberman clears its player spawn areas before the first frame, then destroys cells during playback. Its first frame and later frames therefore need not match GitHub's static grid square for square. Gameplay scores and destroyed-cell counts are not contribution totals.

The upstream action makes best-effort analytics and game-stat requests. Its implementation is not redistributed in this package, and no upstream license is assumed.

```powershell
git pull --ff-only
# Edit README.md, then:
git add -- README.md
git commit -m "Update GitHub profile"
git push
```

The current project links are NutritionScanner, Yukti, Provlepsi-AI and Before-the-Library. Keep the RV University internship status selected/upcoming until user-confirmed facts change it.

If generation fails, open its failed Actions run. The repository's Actions policy must allow abozanona/pacman-contribution-graph and crazy-max/ghaction-github-pages, and the workflow needs contents: write to publish output. No personal token or GitHub Pages site is required. Scheduling can be delayed or disabled after extended repository inactivity.

## Reusing the package for a first upload

Create a public repository named Abhi-eversor under Abhi-eversor, with no starter files. Publish this folder's contents at the repository root. The initial workflow upload to main triggers generation; wait for its green result before expecting the output images. The ZIP contains only main-branch source files, not generated Bomberman SVGs or private review material.
