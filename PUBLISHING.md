# Publishing and Galaga updates

The live profile is [Abhi-eversor/Abhi-eversor](https://github.com/Abhi-eversor/Abhi-eversor). Its root README uses native Markdown, LinkedIn and Kaggle contact buttons, and the original upstream Galaga animation.

## Where the files live

- `main`: README.md, this guide, .gitignore, .github/workflows/galaga.yml and the two contact-button SVGs in assets/.
- `output`: galaga-contribution-graph.svg and galaga-contribution-graph-dark.svg, generated by GitHub Actions.
- `profile-review/`: private local evidence and earlier prototypes, outside the public repository and ZIP.

The README references the SVGs on output using raw.githubusercontent.com URLs. No local Galaga snapshot or generator script is needed on main. Yashraj's snake workflow uses the same separation between workflow source and generated output.

## Automatic generation

[Refresh Galaga](.github/workflows/galaga.yml) uses [abozanona/pacman-contribution-graph](https://github.com/abozanona/pacman-contribution-graph), pinned to `7332e1de7903ab780c3692a4127a59cc13872daa`, with `games: galaga`. Its built-in GitHub token fetches the profile owner's contribution calendar through GitHub's GraphQL API.

The workflow runs:
- When galaga.yml is first uploaded or changed on main.
- Every six hours at **03:17, 09:17, 15:17 and 21:17 Asia/Kolkata**.
- When requested through **Actions > Refresh Galaga > Run workflow**.

Both original GitHub theme SVGs must validate before publication. [crazy-max/ghaction-github-pages](https://github.com/crazy-max/ghaction-github-pages), pinned to `df5cc2bfa78282ded844b354faee141f06b41865`, publishes only dist/ to output and preserves output history. A generation failure leaves the previous output intact. Output commits do not retrigger the main-branch workflow.

The first actual hosted run [completed successfully on 15 October 2026](https://github.com/Abhi-eversor/Abhi-eversor/actions/runs/38701447459). 

GitHub displays animated SVG images, not executable README JavaScript. Original Galaga preserves all visible contribution cells in its first frame, including the October cells previously cleared by Bomberman's spawn areas. The ship then shoots and removes cells during playback, so later frames are not a static calendar. Gameplay scores and destroyed-cell counts are not contribution totals.

The upstream action makes best-effort analytics and game-stat requests. Its implementation is not redistributed in this package, and no upstream license is assumed.

## Maintaining the live profile

Before editing, synchronize the main branch:

```powershell
Set-Location -LiteralPath 'C:\Users\abhia\Desktop\New folder (2)\github_readme\profile-package\Abhi-eversor'
git pull --ff-only
# Edit README.md, then:
git add -- README.md
git commit -m "Update GitHub profile"
git push
```

The current project links are NutritionScanner, Yukti, Provlepsi-AI and Before-the-Library. Keep the RV University internship status selected/upcoming until user-confirmed facts change it.

If dates appear only in your signed-in calendar, check whether private contributions are publicly visible through Profile > Contribution settings > Private contributions. The workflow cannot infer contribution counts GitHub does not expose to its token. See [GitHub's visibility instructions](https://docs.github.com/en/account-and-profile/how-tos/contribution-settings/manage-visibility-settings-for-private-contributions-and-achievements).

If generation fails, open its failed Actions run. The repository's Actions policy must allow abozanona/pacman-contribution-graph and crazy-max/ghaction-github-pages, and the workflow needs contents: write to publish output. No personal token or GitHub Pages site is required. Scheduling can be delayed or disabled after extended repository inactivity.

## Reusing the package for a first upload

Create a public repository named Abhi-eversor under Abhi-eversor, with no starter files. Publish this folder's contents at the repository root. The initial workflow upload to main triggers generation; wait for its green result before expecting the output images. The ZIP contains only main-branch source files, not generated Galaga SVGs or private review material.
