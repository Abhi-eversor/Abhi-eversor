# Abhishek Aryan

**Machine Learning & AI Researcher**

I'm a third-year B.Tech student in Computer Science & Engineering (AI & ML) at **Haldia Institute of Technology**. I study machine learning and build AI systems across different problem domains.

## 🛠️ Projects

- **[NutritionScanner](https://github.com/Abhi-eversor/NutritionScanner):** Android nutrition-label scanner with a compressed detector under 1 MB, TensorFlow Lite inference and on-device OCR.
- **[Yukti](https://github.com/Abhi-eversor/Yukti):** Neuro-symbolic research prototype combining a neural network, learnable feature thresholds and differentiable logical rules on breast cancer cytology data.
- **[Provlepsi AI](https://github.com/Abhi-eversor/Provlepsi-AI):** Browser-based time-series forecasting with nine model families. Pyodide and TensorFlow.js run in Web Workers, with datasets and models stored locally.
- **[Before-the-Library](https://github.com/Abhi-eversor/Before-the-Library):** Gaussian-mixture EM and linear regression implemented from scratch in NumPy.
